# URL을 Markdown으로 변환해 LLM으로 넘기기

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 뽑아 보여 주고, 복사, `.md` 다운로드, ChatGPT·Claude로 열기 중 하나로 바로 넘길 수 있는 한 화면짜리 서비스입니다.

연결된 소스:

- [prototype.html](prototype.html): 승인된 화면 구성, 상태(빈 화면, 변환 중, 결과, 긴 글 결과, 오류), 내보내기 배치는 이 프로토타입을 따릅니다.
- [ui-composition](../../decisions/ui-composition.md): 화면의 component, token, 상태 표현은 이 계약을 따릅니다.

## 사용자에게 보이는 결과

- URL을 붙여넣고 변환하면 페이지 제목과 저자가 머리에, 그 아래 렌더링된 Markdown 본문이 보입니다.
- 결과를 클릭 한 번으로 복사하거나 `.md` 파일로 내려받을 수 있습니다.
- ChatGPT나 Claude 버튼을 누르면 새 탭에서 해당 서비스의 새 대화가 열리고, 고른 프롬프트와 본문이 함께 전달됩니다.
- 화면을 라이트와 다크 테마 사이에서 전환할 수 있습니다.

## 범위

포함:

1. **입력**: URL 입력란, 변환 실행, 입력과 결과를 비우는 지우기 버튼
2. **변환**: 페이지 본문을 Markdown으로 추출. 추출에는 defuddle을 사용합니다.
3. **결과 확인**: 제목·저자 헤더와 렌더링된 Markdown
4. **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기
5. **프롬프트**: 프리셋 3종(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘)과 "직접 입력". 직접 입력을 고르면 텍스트 입력란이 나타나고, 입력한 내용은 저장하지 않습니다.
6. **다크모드 토글**

## 수용 기준

- 공개된 글 URL(예: `https://stephango.com/file-over-app`)을 넣고 변환하면 제목 "File over app"과 저자 "Steph Ango"가 헤더에 보이고, 본문이 Markdown 서식(강조, 문단, 링크 등)대로 렌더링됩니다.
- 변환하는 동안 진행 중 상태가 보이고, 변환 버튼을 다시 누를 수 없습니다.
- URL 형식이 아니거나, 페이지를 가져오지 못했거나, 본문을 추출하지 못하면 화면에 오류 메시지가 보이고 입력한 URL은 그대로 남습니다.
- 지우기 버튼을 누르면 입력란, 결과, 오류가 모두 비워진 처음 상태로 돌아갑니다.
- 저자 정보가 없는 페이지는 저자 자리를 비워 두지 않고 제목만 보여 줍니다.
- 복사하기를 누르면 클립보드에 Markdown 원문이 들어가고, 복사됐다는 피드백이 보입니다.
- `.md` 다운로드를 누르면 Markdown 원문을 담은 `.md` 파일이 내려받아지고, 파일 이름은 페이지 제목에서 만듭니다.
- 프롬프트를 고르지 않은 것이 기본 상태입니다. 프리셋이나 직접 입력을 고르면 ChatGPT·Claude로 보낼 때 본문 앞에 그 프롬프트가 붙습니다.
- 직접 입력을 고르면 텍스트 입력란이 나타나고, 새로고침하거나 다른 프롬프트를 고른 뒤 돌아오면 이전 입력이 남아 있지 않습니다.
- ChatGPT·Claude로 열기는 내용 길이에 따라 다르게 동작합니다.
  - 프롬프트와 본문을 합친 내용이 URL에 실을 수 있는 길이면, 새 탭에서 해당 서비스의 새 대화가 그 내용이 입력된 상태로 열립니다.
  - 그보다 길면, 프롬프트와 본문을 합친 내용을 클립보드에 복사하고 새 대화를 열며, 붙여넣으라는 안내를 화면에 보여 줍니다.
- 다크모드 토글을 누르면 화면 전체가 반대 테마로 바뀌고, 새로고침해도 고른 테마가 유지됩니다.
- 좁은 화면에서도 입력, 결과, 내보내기 동작이 숨겨지지 않고 순서대로 쌓입니다.

## 정해진 제약과 이유

- **본문 추출은 defuddle로 합니다.** 요구 사항이 정한 라이브러리입니다. 0.19.6 버전에서 `defuddle/node`와 `linkedom` 조합으로 실제 글의 제목, 저자, 게시일, 본문 Markdown이 추출되는 것을 확인했습니다.
- **ChatGPT·Claude 전달은 길이에 따라 URL 채우기와 클립보드 복사 중 하나를 고릅니다.** 사용자가 정했습니다. 짧은 글은 클릭 한 번으로 끝나고, 긴 글도 잘리지 않고 전달됩니다. 항상 클립보드를 쓰면 매번 붙여넣어야 하고, 항상 URL을 쓰면 긴 글이 잘립니다.
- **직접 입력한 프롬프트는 저장하지 않습니다.** 요구 사항이 1회용으로 정했습니다.
- **내보내기 동작은 결과 머리(제목·저자 아래)에 툴바로 둡니다.** 사용자가 세 안(결과 위 툴바, 하단 고정 바, 오른쪽 사이드 패널)을 비교해 골랐습니다. 변환 직후 가장 먼저 눈에 들어오고, 휴대폰에서도 본문을 가리지 않습니다. 순서는 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기이고, 그 아래에 프롬프트 선택이 옵니다.

## 가정 (바꿔도 되는 기본값)

- 브라우저는 CORS 때문에 다른 사이트의 HTML을 직접 가져올 수 없으므로, 페이지를 가져와 변환하는 일은 서버에서 합니다.
- 프롬프트는 ChatGPT·Claude로 열 때만 붙습니다. 복사하기와 `.md` 다운로드는 본문만 담습니다. 요구 사항이 프롬프트를 "열기" 항목 아래에 두었기 때문입니다.
- 한 번에 프롬프트는 하나만 고를 수 있고, 같은 선택이 ChatGPT와 Claude 버튼에 함께 적용됩니다.
- 프롬프트와 본문 사이에는 빈 줄을 하나 둡니다.
- 결과 화면은 렌더링된 Markdown만 보여 주고, 원문 보기 전환은 두지 않습니다.
- 헤더에는 제목과 저자 외에 출처 사이트 이름을 작게 함께 보여 줍니다.
- 다크모드의 첫 상태는 운영체제 설정을 따릅니다.
- URL 길이 한도는 인코딩 후 약 8,000자로 잡고, 구현 때 두 서비스에서 실제로 열리는지 확인해 조정합니다.
- 변환 기록은 남기지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.
- 복사, 다운로드, ChatGPT·Claude로 열기의 결과는 잠깐 떠 있다 사라지는 알림으로 알려 줍니다. 긴 글을 클립보드로 넘길 때는 붙여넣으라는 안내를 조금 더 오래 보여 줍니다.
- 변환을 새로 시작하거나 지우기를 누르면 고른 프롬프트도 초기화됩니다.

## 범위 밖

- 로그인, 변환 기록, 프롬프트 저장: 요구 사항에 없고, 직접 입력은 1회용으로 정해져 있습니다.
- JavaScript로만 본문을 그리는 페이지나 로그인이 필요한 페이지의 추출 보장: 서버가 받은 HTML에 본문이 없으면 오류로 처리합니다.
- ChatGPT·Claude 외 다른 LLM 서비스.
- 스펙이 요구하지 않은 보안 하드닝, 요청 제한, 성능 방어: 학습용 템플릿의 검증 예산 밖입니다.

## 남은 위험

- ChatGPT(`chatgpt.com/?q=`)와 Claude(`claude.ai/new?q=`)의 프롬프트 채우기는 공식 계약이 아니어서 언제든 바뀔 수 있습니다. 바뀌면 짧은 글도 클립보드 경로로 가야 합니다.
- 실제 URL 길이 한도가 서비스마다 다를 수 있습니다. 한도를 잘못 잡으면 짧은 쪽 경로에서 글이 잘리거나 열리지 않습니다.
- 일부 사이트는 서버 요청을 막거나 JavaScript로만 본문을 그려서 추출이 실패할 수 있습니다.
